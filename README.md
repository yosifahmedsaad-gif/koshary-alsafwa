# Koshary Alsafwa

A bilingual Arabic/English storefront and local-demo kitchen display for Koshary Alsafwa.

## Run locally

Open `index.html` in a browser. The site uses the assets in `assets/`, the styles in `css/`, and the application code in `js/`.

## GitHub Pages

This site is a static website. In the repository settings, enable GitHub Pages from the `main` branch and the root (`/`) folder. Once published, the site is available at:

`https://yosifahmedsaad-gif.github.io/koshary-alsafwa/`

## Trial limitations

- Orders, menu changes, offers, and trial sales are stored locally in the browser and are not shared across devices.
- The kitchen PIN (`1234`) is a demo convenience, not production authentication.
- Payment screens do not charge, transfer, or collect payment credentials.
- Do not use this static demo as a production ordering, payment, or customer-data system.
